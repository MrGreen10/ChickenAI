# ChickenAI
ChickenAI harici kütüphane bağımlılığı olmayan C++ ile yazılmış bir kural tabanlı karar motoru projesidir hem son kullanıcı hem de benden daha iyi kod yazanlara altyapı olması amacıyla tasarlandı.
# Önemli Not!
Bu proje altyapı olması amacıyla tasarlandı lütfen dertlerinizi anlatmayın.Dertleriniz için profesyonel destek alın yada bir yakınınızla konuşabilirsiniz.
# Proje Hakkında
ChickenAI anahtar kelimeleri yakalayıp cevap hazırlamak için anahtar kelimeyle eşleştirilen kelimeleri seçerek(giriş,gelişme,sonuç olarak ama bazen giriş,sonuç olabiliyor.) cevap oluşturur.
